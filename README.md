## 📌 Sobre o Projeto

Este projeto representa o ponto de partida da minha jornada no desenvolvimento web front-end. O objetivo principal foi consolidar os fundamentos da web, transformando conceitos teóricos em uma interface funcional, responsiva e agradável de usar.

O site conta com um layout limpo, navegação intuitiva e funcionalidades interativas desenvolvidas com JavaScript puro (Vanilla JS).

---

##  Funcionalidades Principais

-  **Dark / Light Mode:** Alternador de tema personalizado com chaveamento suave.
-  **Persistência com LocalStorage:** O tema escolhido pelo usuário é salvo no navegador e mantido mesmo após atualizar ou fechar a página.
- **Anti-Flicker Script:** Prevenção do flash de tema claro (*FOUC*) ao carregar a página em modo escuro.
-  **Header Interativo:** Navegação com atalhos, barra de pesquisa e links externos.
-  **Design Responsivo:** Estrutura adaptável para diferentes tamanhos de tela.

---

##  Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de todo o conteúdo e componentes.
- **CSS3:** Estilização, layout (Flexbox), variáveis CSS, transições e adaptação visual dos temas claro/escuro.
- **JavaScript (Vanilla):** Manipulação da DOM, escuta de eventos de clique e persistência de dados via `localStorage`.
