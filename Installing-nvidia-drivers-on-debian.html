Why its so HARD? - How to install NVIDIA-DRIVERS on Debian 13:

In this year i decided to move on Linux as my day-to-day OS and i choose Debian to be my very first distro. Until this time Debian are in the 13 version, but my began when i needed to install the NVIDIA-DRIVERS... for some reason, this task is practically imposible in my case due to the fact that i have a new-gen GPU (RTX 5060Ti)but after a few searchs (and a lot of Headaches) i manage to resolve the situation. I'll explain how:

DISCLAIMER: Before we started, this method solved MY problem with MY gpu, keep that in mind. Probally if u had an older one u actually doesn't need to follow this tutorial, ok?

After you downloading Debian u can follow these steps:

Run a Terminal -> sudo su (to root user) -> apt install extrepo -> extrepo update -> extrepo search nvidia | less -> extrepo nvidia-cuda -> cd /etc/apt/sources.list.d/ -> apt update -> apt install build-essential linux-headers-amd64 -> apt instal nvidia-open

After that u can check if worked using "nvidia-smi" command in Terminal. Something like the photo above should runs(using your GPU Specs of course).
